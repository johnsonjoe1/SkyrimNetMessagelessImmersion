# SkyrimNet Messageless Immersion 0.7.2.1

Hotfix release focused on reducing repeated thoughts, correcting cooldown handling, and covering additional mod events. Changes since 0.7.2:

## Fixes and timing improvements

- Lockpick replenishment thoughts now trigger only when you previously had three or fewer lockpicks, instead of fewer than 20. Replenishment and last-three-lockpicks thoughts each have a separate 180-second cooldown; running out of lockpicks still triggers an immediate thought.
- AND nudity-change thoughts now wait at least 30 seconds after loading a game and have a 40-second cooldown to reduce repeated comments during clothing changes.
- Fixed SLAC player-scene stage timing: stage thoughts now wait 40 seconds after the scene starts and at least 40 seconds between subsequent comments. Nearby NPC scene starts and endings each have a separate 180-second cooldown.
- Fixed slap and grope notification cooldowns incorrectly sharing the timer used for approaching SLAC creatures. Slap and grope thoughts now use their own shared 30-second cooldown.
- Added separate 120-second cooldowns for the application and removal of the Licenses magic-suppression effect.
- Increased the cooldown between Battle Fuck stripping-stage thoughts from 20 to 40 seconds.
- Extended water-entry handling to recognize the additional swimming effect from another mod, using the same five-minute entry cooldown to reduce overlapping comments.
- Furniture thoughts are now eligible from the first use, without an initial cooldown caused by plugin startup.
- Spontaneous Bimbos of Skyrim corruption complaints now require corruption above 80 and below 99, instead of above 60 and below 99.

## Additional event coverage

- Added expiration thoughts for weapon, magic, armor, bikini, clothing, crafting, and trading licenses, travel permits, and life insurance. These use the existing shared license-thought cooldown.
- Added a player thought for the Devious Devices plug-moan broadcast.
- Recognized the Devious Devices chargeable-plug effect "It keeps going, and going." as handled, without adding a thought alongside SkyrimNet-UDNG's existing reactions.
- Added filtering for a redundant Jail Rape ending broadcast.

No new configuration options were added in this hotfix.
